### 二、切片定义（每片必须独立绿）

| 片 | 内容 | 产出文件 | 回滚点 |
| --- | --- | --- | --- |
| **S1** | 抽出回合状态机 | `src/host/domain/turn.ts`（`Outcome`、`settle` 优先级、`pending`、`unknown` 的判定） | 单提交回滚，adapter 恢复内联 |
| **S2** | 抽出绑定与存储 | `src/host/domain/binding.ts` + `src/host/domain/binding-store.ts`（`session-store.ts` 移入） | 单提交回滚 |
| **S3** | 拆分传输层 | `src/host/transport/acp-process.ts`（进程/`killTree`/stderr） + `src/host/transport/acp-protocol.ts`（握手/session/prompt/cancel/config） | 单提交回滚 |
| **S4** | 拆分客户端 | `src/client/service/selection.ts` + `src/client/view/model-seat/{rail,search,list,panel}.tsx` | 单提交回滚 |

**顺序约束**：S1、S2 先行（是 S3/S4 的依赖前提）；S3 与 S4 可并行。

### 三、每片的验收（缺一不可）

1. `node node_modules/typescript/bin/tsc --noEmit` 退出码 0。
2. `node node_modules/vitest/vitest.mjs run` 全绿；**测试文件数不减（基线 27 个 / 204 项，2026-10-28 实测）、断言不改**。
3. 新增 `tests/layering.test.ts`：断言四件事——
   - `src/host/domain/**` 不得 import `../surface/` 或 `../transport/`；
   - `src/host/domain/**` 源码不得出现 `ctx.`（不碰宿主服务）；
   - `src/client/service/**` 不得 import `react`；
   - 任何 `.ts/.tsx` ≤ 400 行（host/client）。
4. S1–S3 完成后，`acp-adapter.ts` 应降到 ≤600 行且只剩编排；S4 完成后 `model-seat.tsx` 不再存在（拆成 4 个 ≤300 行文件）。
5. 真机冒烟（重构全部完成后一次性做）：一轮 ACP 对话 + 工具卡 + 打开轨迹视图，行为与重构前一致。

### 四、明确的「不做什么」

- 不改任何行为、不改 `plugin:acp/*` 记录名、不改 `acpSessionControl` 服务名、不改包名与 bundle id。
- 不因为分层而扩大 `src/shared`（它是两端兼容成本最高的地方）。
- 不一次性搬完：四片必须分别提交。
