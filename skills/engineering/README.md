# engineering

Repo-native engineering skills: how to implement small steps, diagnose bugs,
research external facts, practice TDD, and work on this DSH plugin.

| Skill | One-liner |
| --- | --- |
| [implement](implement/SKILL.md) | Small-step TDD implementation with a success-criteria gate — use for any feature or change. |
| [diagnosing-bugs](diagnosing-bugs/SKILL.md) | Reproduce → root cause → fix at the cause → prove with a test. |
| [research](research/SKILL.md) | Look up an external/library fact against primary sources and write it into `docs/` with citations. |
| [tdd](tdd/SKILL.md) | Write the failing test, watch it fail, implement, make it green, keep `tsc` clean. |
| [dsh-plugin](dsh-plugin/SKILL.md) | Develop this DeepSeek Harness ACP plugin — structure, runtime faces, build, install, safety. **Read this first.** |
