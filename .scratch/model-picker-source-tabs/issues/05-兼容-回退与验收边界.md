## Answer（grilling 定稿，2026-10-28）

1. **默认形态**：影子选择器就是正式形态、**默认开启、不加配置开关**。可选回原生只依赖三条自动回退，不提供手动切换（少一个配置字段与一个分叉路径）。
2. **宿主边界**：只保证 **0.2 核心**（0.2.1-rc.3 已真机验收）。0.1 核心的 client 半边本来就不 apply，自然退回原生——**不写 0.1 特判**。README 写清支持范围。
3. **双入口口径**：`/model` 保持原生无 tab、不试图同步外观、插件不弹提示；仅在 README「限制」写一句差异说明。
4. **验收深度**：单测覆盖渲染（两级 pane / rail 分组 / 空态 / 失败 tab / 锁定 / subagent 不渲染）与动作（fake directory 的 select、effort）；真机只保留**一次性手工清单**，不建自动化 e2e（本仓无该基建）。
5. **升级复核**：把「影子是引擎行为、非文档化扩展点、无版本协商」写入 `docs/dsh-plugin-dev/09-compatibility.md` 风险表，并定触发条件：DSH 升级到新 minor（0.2→0.3）或 `ui-model-selection` / `ui-slots` 发生变更时，必须重跑真机清单并更新证据。

**三条回退边界（引用 #03/#04 结论，升级时必须保底）**
- 座位未声明 / 0.1 无 `slots` / 有 `slots` 无该 key → `slots.inject` 静默等待，不报错、不影响其它功能。
- 注册抛错（同 priority、子插槽重复声明等）→ try/catch + `console.error`，返回空 disposer，原生继续渲染。
- 渲染崩溃 → error boundary 兜住并提供可读文案；即使边界失守，引擎也只是把 entry 一次性 abdicate 回落原生，**不会连带 `/model` 与目录服务**。

**#04 已暴露的真实失败模式（必须写进验收清单）**
- inject 作用域缺 `remote` / `remote.session` → entry 渲染抛错后被引擎静默退役，表现为「我们的选择器完全不出现、也没有任何报错」，最难排查。验收时若「看不到影子」，第一步查 console 的 `slot entry crashed in 'conversation.input.model'`。

**真机一次性清单（精简自 #03 §8.3）**
1. 图标 rail 出现（★收藏 / 平台 / 每个已启用 ACP），切 tab 正常；单来源 tab 不显示供应商标题，DSH tab 显示吸顶分组标题。
2. 点击先出「模型 / 推理」两级；切模型后 trigger 更新；切到 ACP 模型 trigger 外显 ACP 名。
3. 搜索：全目录 > 4 时出现，只过滤当前来源。
4. `/model` 未变更；从 `/model` 选完，影子 trigger 同步。
5. 收藏：☆ 只收藏不选模型、收藏 tab 聚合、hover 才显星。
6. 停用一个 ACP → 其 tab 消失、设置页行保留可重开、已保存选择报 `model-unavailable`。
7. subagent 会话不渲染座位；生成中/锁定时 trigger 禁用。
8. 刷新页面 / 重启桌面端各一次，确认没有回落原生（检查 console 无 `slot entry crashed`）。

**未实测**：窄视口（<640px）下的固定卡片尺寸、0.1 核心（本轮不承诺）。
