# 05: 跨来源切换告知与三级降级

**What to build:** 用户在同一来源内换模型或推理等级时完全不被打扰；跨来源（dsh 原生 ↔ ACP ↔ 另一个 ACP）时先看到一次风险说明并确认，拒绝则原选择不变。完成后「切换会不会丢上下文」不再是用户需要靠猜的事。

**Blocked by:** 04（S4 先把选择器拆成数据层, 提示逻辑才有干净的落点）

**Status:** resolved

- [ ] 同来源内换模型 / 换推理等级：不出现任何提示
- [ ] 跨来源切换：出现一次确认，说明三项风险（内部会话重建、历史压平成文本、对方工具过程不可见）
- [ ] 确认框拒绝后，当前选择保持原值不变
- [ ] 同一会话同一「来源对」只问一次；A→C 仍会问
- [ ] 从 `/model` 弹窗触发的跨来源切换同样被捕获
- [ ] 无审批服务时：放行 + 一条不阻塞提示，不卡住切换
- [ ] 审批策略为 `never`（完全权限预设）时：走提示降级，**不**静默失败
- [ ] 文案走插件 i18n 命名空间，中英各一份
- [ ] `tsc --noEmit` 退出码 0、`vitest run` 全绿

触发点：客户端观察到会话级模型目录的当前选择变化（该目录与 `/model` 弹窗共用同一份实例，因此弹窗绕行也能被捕获）。
