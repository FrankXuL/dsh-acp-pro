## 范围

选择器接上真实配置来源：

1. **来源判定**：`已启用 ACP 路由集合` 从 `configForms.get(PLUGIN_ID).getSnapshot().value.agents` 读，且**过滤掉 `enabled === false`**；未启用的路由不得出现在 rail。
2. **图标**：实现 `resolveIcon(profile)` —— 内置名映射表（claude / codex / gemini / deepseek / openai / opencode …）→ inline SVG；emoji/URL → 文本或 `<img>`；未知/非法 → displayName 首字母。
3. **收藏读写**：新增 `src/client/service/favorites.ts`，通过 `ConfigForm.mutate()` 写顶层 `favorites`（替换式整数组写入），并提供读取投影；选择器改为从该投影取收藏，不再用 `localStorage`。
4. **停用来源的收藏**：收藏项在目录里没有对应组时自然不显示（现状已如此，补单测锁定）。

## 约束

- 不新增 host RPC；收藏只走 `ConfigForm.mutate()`。
- 写入要串行/合并，避免连点星产生并发写冲突。
- `favorites` 变化不得引起选择器重新 load 目录。

## 验收

- 单测：`enabled:false` 的路由不出 rail；`icon` 三种取值分别解析正确；toggle 收藏发出正确的 `mutate` ops（整数组替换）；停用来源的收藏不显示。
- 真机：收藏后重启仍在（证明写进配置而非 localStorage）。
